# 3 «А» класс — расписание уроков

Небольшое веб-приложение с расписанием уроков: показывает, какой урок идёт
прямо сейчас, сколько до звонка и что задано на дом. Сделано под телефон и
планшет, ставится на домашний экран и работает без интернета.

**Адрес:** https://selivanovas.github.io/school-schedule/

## Что умеет

- **«Сейчас идёт»** — верхняя плашка сама показывает текущий урок, полосу
  времени до звонка и что будет дальше. В перемену — сколько до урока,
  после уроков — «на сегодня всё», в выходной — какой урок первым в
  понедельник.
- **Дни недели** — переключаются кнопками Пн–Пт, свайпом влево-вправо и
  стрелками на клавиатуре. При открытии показывается сегодняшний день.
- **Домашние задания** — нажмите на урок, впишите, что задано, и отметьте
  галочкой, когда сделано. На карточке урока появится 📝 или ✅.
- **Тёмное оформление** — кнопка 🌗 в правом верхнем углу переключает
  «как на телефоне» → светлое → тёмное.
- **Печать** — кнопка «Распечатать неделю» выводит всю неделю одной
  таблицей на лист А4.
- **Без интернета** — после первого открытия приложение работает офлайн.

## Как поменять расписание

Всё расписание лежит в одном файле — [`data.js`](data.js). Другие файлы
трогать не нужно.

Урок:

```js
{ from: '09:00', to: '09:40', title: 'Математика' },
```

Не-урок:

```js
{ from: '08:00', to: '08:45', type: 'breakfast' },   // завтрак
{ from: '08:45', to: '09:00', type: 'circle'    },   // утренний круг
{ from: '09:40', to: '09:50', type: 'break'     },   // перемена
{ from: '10:30', to: '10:40', type: 'snack'     },   // 2-й завтрак
{ from: '13:00', to: '13:30', type: 'lunch'     },   // обед
{ from: '13:30', to: '15:00', type: 'homework'  },   // выполнение ДЗ
```

Урок ещё не известен — `title: null`. Весь день не известен — `thu: null`.
Промежутки между записями приложение рисует само.

Новый предмет получит свой цвет и картинку, если добавить его в справочник
`SUBJECTS` в том же файле:

```js
'Информатика': { icon: '💻', color: 'cyan' },
```

Доступные цвета: `crimson`, `rose`, `amber`, `peach`, `blue`, `green`,
`teal`, `orange`, `violet`, `indigo`, `pink`, `cyan`, `sky`, `lime`,
`slate`.

### ⚠️ После правки — увеличить номер версии

Иначе у тех, кто уже поставил приложение на телефон, останется старое
расписание из кэша. Нужно поднять на единицу **в двух местах**:

1. в [`index.html`](index.html) — `?v=1` у `styles.css`, `data.js`, `app.js`;
2. в [`service-worker.js`](service-worker.js) — `CACHE_VERSION` и такие же
   `?v=1` в списке `SHELL`.

## Что где лежит

| Файл | Зачем |
|---|---|
| `data.js` | расписание, предметы, дни недели — **единственный файл для правок** |
| `index.html` | каркас страницы |
| `styles.css` | оформление, тёмная тема, планшет, печать |
| `app.js` | часы «сейчас идёт», домашки, переключение дней |
| `service-worker.js` | работа без интернета |
| `manifest.json` | установка на домашний экран |
| `icon.svg`, `icon-maskable.svg` | исходники иконки (PNG собираются из них) |
| `fonts/` | шрифт Nunito — лежит здесь, а не на стороннем CDN |

## Про домашние задания

Записи хранятся **только на том устройстве, где их ввели** — сервера у
приложения нет. Домашка на телефоне мамы не появится у ребёнка на планшете.
Задание привязано к дню недели и времени урока, поэтому на следующей неделе
запись останется на месте — стереть всё сразу можно кнопкой «Очистить все
домашки» внизу страницы.

## Проверить локально

```bash
npx --yes http-server . -p 8080 -c-1
# затем открыть http://localhost:8080/
```
